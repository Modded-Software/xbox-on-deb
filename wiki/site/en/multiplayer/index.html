Multiplayer

Blizzard promised StarCraft: Ghost a 16-player online mode with classes and several match types. The leaked build has no working multiplayer. The mode was built later, after the game moved to Swingin' Ape Studios, so the artifact predates it.

The promise

The 2005 official FAQ describes 16-player multiplayer over Xbox Live and Battle.net. The Covert Ops section of the game's website details the classes and modes. The public plan included:

FeatureDetail as announced
Player countUp to 16 players.
NetworksXbox Live and Battle.net.
ClassesGhost, Light Infantry, Marine, Firebat.
ModesDeathmatch, Team Deathmatch, Capture the Flag, King of the Hill, Capture the Base (also called Mobile Conflict), and Invasion.
Playable ZergZerg multiplayer units were announced as playable.

The reality in the build

The May 8 2004 build contains no functioning network play. One executable in the Xbox family shows an "Online Services" menu string, and the class and mode names survive in the website copy and in lore assets, but there is no match logic and no working network stack. The multiplayer era begins after Nihilistic's departure, when Swingin' Ape Studios rebuilt the game around competition and revealed a multiplayer build at BlizzCon 2005.

What this means for the artifact

Multiplayer is the largest single gap between the marketed game and the leaked build. Anyone assessing the build should treat it as the Nihilistic single-player foundation only. The gap analysis records the same conclusion in its feature table, and the development history explains why the mode arrived with the second studio.
