Systems

StarCraft: Ghost combined stealth traversal, psionic powers, and StarCraft tactical support. The build contains the single-player systems, and it also contains assets and text for features no enabled mission uses. This page groups each system by its state in the build.

Present works in an enabled mission. Unwired exists as assets or text but no enabled mission uses it. Absent not found in the build.

Psi powers

PowerStateEvidence
Cloak Present Enabled on every active mission, with a dedicated tutorial and description table.
Vision and thermal sight Present Enabled in The Fujita Pinnacle alongside cloak.
Psi speed (sonic speed) Unwired A text table and power entry exist, but the power is set only on disabled missions.
Psi shield and psi storm Absent Named only in the chronicle file's header grammar. No implementation.

Movement and acrobatics

Traversal is part of the wired single-player loop. Tutorial tables cover moving, jumping, climbing, wire traversal, and mantling. The official 2004 FAQ promised these abilities.

Enemies and factions

Terran and Zerg units are present and rendered. Full unit biographies run from index 100 to 247 in the text tables, including Protoss and Zerg creatures. The Protoss units are modeled and named but have no enabled mission, because the Protoss arc was never wired. The complete rosters appear in the media inventory.

Content-rich, wiring-poor

Several tutorial tables describe features with no enabled mission, including target lock, silent disable, the minimap, the psi blade, the shock glove, and the lockdown canister. The system assets span the whole announced design while the playable mission graph exposes a fraction of it. The gap analysis compares the two directly.
