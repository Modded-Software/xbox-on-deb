The leak

The leaked archive holds two different StarCraft: Ghost builds. The newer one is an Xbox development build compiled on May 8 2004. The older one is a 2002 Win32 demo made for the Tokyo Game Show. This page describes the files, how the build runs, and the command-line options and debug features found inside.

Two executable families

The archive ships one family for Windows and one for the Xbox. Telling them apart matters because only one runs under Wine or Proton directly.

FamilyFilesTarget
Win32 demo Star.exe, Star_d.exe, Star_u.exe Windows, Direct3D 8 and DInput8; the 2002 Tokyo Game Show demo
Xbox build Ghost.xbe (release), GhostR.xbe, GhostU.xbe, update.xbe, plus Ghost.exe, GhostR.exe, GhostU.exe and their .map and .pdb files Original Xbox, imports xboxkrnl.exe

How it runs

The Xbox build runs in Cxbx-Reloaded, an original Xbox emulator. On Linux, Cxbx runs under GE-Proton (Wine, DXVK, VKD3D), with its Direct3D 9 output translated to Vulkan through DXVK. The Win32 demo runs directly under GE-Proton with Direct3D 8. The repository that hosts this wiki documents the setup.

Command-line switches

The community teardown on BetaArchive lists several command-line options in the build:

SwitchEffect
/devmodeDevelopment mode.
/consoleOpens the in-game console.
/windowRuns in a window.
/tgsTokyo Game Show demo mode.
/levelLoads a named level directly.
/nosoundDisables audio.
/novidSkips the intro video.

Debug and unlock features

A development profile named Nova unlocks all missions. Single-player mission definitions live in a chronicle file, ghostsp.nsc, where disabled missions are commented out and can be re-enabled. The build also writes an engine configuration file named masquerade.ini, which preserves the NOD engine's connection to Vampire: The Masquerade - Redemption, the 2000 Nihilistic role-playing game.

Why the build matters

The build sits at the handoff between the two developers. It is a Nihilistic-era vertical slice, with the core stealth-combat loop and several psi powers working, and most of the marketed feature set present only as assets, text, and disabled mission definitions. The gap analysis covers that comparison in detail.
