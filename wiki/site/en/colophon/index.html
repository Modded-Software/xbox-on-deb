Colophon

In the spirit of the StarCraft: Ghost era, this wiki is a documents-first static site. Every route is a complete HTML document that renders and reads with JavaScript disabled. A few kilobytes of vanilla JavaScript upgrade same-origin navigation using the browser's own Navigation API and View Transitions. There is no framework, no build step, no webfont, and no third-party request.

Structure

  • One hand-written stylesheet at /assets/css/main.css.
  • Three ES modules at /assets/js/ for navigation upgrades.
  • Per-route documents at /en/<route>/index.html.
  • A route registry at /assets/routes.json.

Accessibility

Each page carries one heading, a skip link, header, main, and footer landmarks, a labelled primary navigation, and a live region that announces route changes. Focus moves to the heading on navigation. The target is WCAG 2.2 AA.
