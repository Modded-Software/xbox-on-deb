Vision vs build

Blizzard announced a broad feature set between 2002 and 2006. The leaked May 8 2004 build contains a narrower vertical slice of it. This page compares the announced game with the artifact, so the difference between what was promised and what exists is explicit.

Reading the gap

  • The single-player stealth-action core survived. Nova, cloak, sight, the sniper rifle, several calldowns, and acrobatic traversal all function, which matches the Nihilistic developers' later recollection of a strong stealth level and a Zerg level.
  • The advertised breadth was mostly aspirational at this date: multiplayer, the Protoss arc, most psi powers, broad vehicle play, and the 12 to 15 hour length.
  • Much of that breadth exists as data, not gameplay. That distinction matters for anyone modding the build or judging what the second studio inherited.
  • The later Swingin' Ape build is not in this leak, so the multiplayer and next-generation features described from 2005 onward cannot be assessed from the artifact.
